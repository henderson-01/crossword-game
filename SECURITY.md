# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

I take the security of Crossword Game seriously. If you believe you've found a security vulnerability, please report it to us.

### Guidelines

1. **Do not** create a public GitHub issue for security vulnerabilities.
2. Instead, use GitHub's **Security Advisories** feature:
   - Navigate to the **Security** tab in this repository.
   - Click on **Report a vulnerability**.
   - Fill out the advisory form with details about the vulnerability.
3. Include a description of the vulnerability and steps to reproduce it.
4. We will acknowledge receipt within 48 hours and provide a timeline for a fix.

### What to Expect

- I will confirm receipt of your report.
- I will investigate and determine the impact of the issue.
- I will release a fix and update the documentation.
- I will credit you for the discovery (unless you prefer anonymity).

Thank you for helping keep Crossword Game secure!
